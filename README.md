# Калькулятор НК / сварки — модули по видам работ

Пока виды работ **разделены** для глубокой проверки. Позже соединим в единый калькулятор.

## Модули

| Вид | Файл | Что внутри |
|-----|------|------------|
| НК | `src/work-types/ndt.mjs` | Методы, тарифы, точки, зависимости объекта, бригада |
| Сварка | `src/work-types/welding.mjs` | Стыки/п.м., роли сварщик/помощник, геометрия |
| Логистика | `src/work-types/logistics.mjs` | Город/адрес → база, билеты, отели, auto-транспорт |
| Роли полей | `src/field-roles.mjs` | Матрица зависимостей object × workType |
| База городов | `src/data/cities.mjs` | Усреднённые билеты и отели |

## Лаборатории

```bash
npm run lab
```

- http://127.0.0.1:4173/labs/
- `/labs/ndt.html` — только НК
- `/labs/welding.html` — только сварка
- `/labs/logistics.html` — город → билеты/отели/auto

### Логистика

При вводе города подтягиваются из базы:

- расстояние от Москвы
- усреднённые билеты (авто / поезд / авиа / автобус)
- усреднённый отель за ночь
- **транспорт auto**: ≤200 км авто, ≤900 км поезд, иначе самолёт

Очистка города сбрасывает суммы; очистка адреса — нет.
