# Калькулятор стоимости НК и сварочных работ

Одностраничный HTML-калькулятор предварительной стоимости неразрушающего контроля и сварки.

## Открыть

Откройте в браузере файл [`ndt-welding-calculator.html`](ndt-welding-calculator.html)  
(или [`index.html`](index.html) — копия того же файла).

## Возможности

- Типы работ: НК / сварка / сварка + НК
- Методы: ВИК, УЗК, РК, ПВК, МК, УЗ толщинометрия
- Коэффициенты толщины, диаметра, доступа и срочности
- Логистика (30 км бесплатно, далее 35 ₽/км)
- Копирование данных для сделки и печать КП

## Тесты

```bash
npm install
npm test
```

Проверки (Puppeteer + Chrome): матрица зависимостей объектов, тип работ, формулы, логистика, РК/точки, игнор диаметра для металлоконструкций. Отчёт и скриншоты — в `test-artifacts/`.
